# Hanzi Cards — iPhone Chinese flashcards

A small installable web app (PWA) designed for iPhone/iPad.

## Features
- Chinese character + English meaning
- Finger/Apple Pencil writing canvas
- Stroke count and stroke-order hint
- Tone-marked Hanyu Pinyin and example phrase
- Again / Hard / Good / Easy grading
- Local attempts and streak tracking
- Offline support after first load

## iPhone installation
Open the GitHub Pages site in Safari, choose **Share → Add to Home Screen**, then open Hanzi Cards from the Home Screen.

## Adding cards
Edit the `cards` array near the top of `app.js`.

## Current limitation
The writing canvas allows stroke practice and displays a textual stroke-order hint, but does not yet automatically validate the user's handwritten stroke paths.
